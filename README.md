# Frisbeer LiveScore Bot

[![Tests](https://github.com/jburn/frisbeer_live_score/actions/workflows/tests.yml/badge.svg)](https://github.com/jburn/frisbeer_live_score/actions/workflows/tests.yml)

Telegram bot for broadcasting Frisbeer game status live.

Includes a handy interface to control the broadcast from a private chat and formats output into a broadcasting channel.
